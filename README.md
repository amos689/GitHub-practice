# GitHub-practice

A small repository for practicing the GitHub contribution workflow: fork, branch, commit, open a pull request, review, and merge.

## Try your first contribution

1. Fork this repository into your own GitHub account.
2. In your fork, create a branch with a short name that describes your change.
3. Make one focused improvement, such as clarifying a sentence or adding a useful practice note, then commit it with a descriptive message.
4. Open a pull request with **Albert1524/GitHub-practice:main** as the base and your fork's feature branch as the head.
5. Explain what changed and how you checked it. Review the **Files changed** tab before submitting.
6. If the maintainer requests changes, commit them to the same branch; the existing pull request will update automatically.

A closed pull request is not necessarily merged. The purple **Merged** status confirms that the change was accepted into the target branch.

## Keep a practice change easy to review

- Give each pull request one clear purpose.
- Include only the files needed for that purpose.
- Check Markdown formatting and any links you add.
- Keep passwords, tokens, and personal data out of commits.
